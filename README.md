This repository contains training data and information for the Tajik-Farsi transliteration shared task for the SilkRoadNLP workshop at EACL 2027.

Workshop Website: [https://www.silkroadnlp.org/](https://www.silkroadnlp.org/)

CodaBench Page: [https://www.codabench.org/competitions/18385/](https://www.codabench.org/competitions/18385/)

Teams MUST fill out the registration form [here](https://forms.gle/vytuy4m6o9mFJNCb8).

## Tracks 
The task has two tracks; teams may participate in one or both:
* Cyrillic → Perso-Arabic. Given Tajik text in Cyrillic, produce the Perso-Arabic rendering.
* Perso-Arabic → Cyrillic. Given Tajik text in Perso-Arabic, produce the Cyrillic rendering.

Rankings are computed per track. A combined (macro-averaged) ranking is reported for information.


## Training Data

The training data is provided in TG-FA_sharedtask.zip as two files:
1. validated.tsv
2. unvalidated.tsv

Each row contains a Tajik-Farsi transliteration pair.

A more detailed description of the training data can be found on the [CodaBench page](https://www.codabench.org/competitions/18385/).
For any questions regarding which outside datasets are permissible, contact the workshop organizers.
